Thirugnanasambandar Nursery & Primary School - static website
==============================================================
Open index.html in any browser, or upload the whole folder to any web host
(Netlify, GitHub Pages, cPanel, etc.). No build step is needed.

Pages: index, about, correspondent, academics, admissions, rules, gallery, contact (.html)
Styles: assets/css/style.css   Scripts: assets/js/main.js
Photos: assets/img/            Videos: assets/video/

Before going live, replace the placeholders in correspondent.html
(search for "REPLACE"):
  - Correspondent's name and photo
  - Chairman, Secretary and Principal names and photos
Put photos in assets/img/ and swap the initials <span> for an <img> tag.
The Correspondent's message is a draft - edit it as needed.
